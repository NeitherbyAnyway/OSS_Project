# 라이선스 비교 및 선정 근거

## 검토 목적

이 저장소는 GitHub 협업과 DORA 지표 자동화를 실습하는 교육용 공개 프로젝트입니다. 코드를 재사용하기 쉽게 공개하면서 저작권 표시를 보존하는 것을 우선합니다.

## 비교

| 라이선스 | 재사용과 배포 | 특허 조항 | 주요 고려 사항 |
| --- | --- | --- | --- |
| MIT | 상업적 사용과 수정·재배포를 폭넓게 허용 | 명시적인 특허 허여 조항 없음 | 짧고 단순하며 저작권·허가 고지를 보존해야 함 |
| Apache-2.0 | 허용적이며 수정·재배포 가능 | 명시적 특허 허여와 특허 소송 관련 조항 포함 | NOTICE 및 라이선스 고지 등 준수 항목이 더 많음 |
| GPL-3.0 | 사용·수정·배포 가능 | 특허 관련 조건 포함 | 배포하는 파생 저작물에 동일한 라이선스와 소스 제공 의무가 적용될 수 있음 |

## 선정 기준과 결정

1. 수업과 외부 기여자가 프로젝트 코드를 쉽게 재사용할 수 있어야 합니다.
2. 저작권 표시와 라이선스 고지는 보존해야 합니다.
3. 현재 프로젝트에는 특허 포트폴리오를 관리하거나 파생 배포물의 공개를 강제할 요구가 없습니다.
4. 관리 부담이 낮고 GitHub 기반 실습에 널리 이해되는 조건이 적절합니다.

이 기준에 따라 **MIT License**를 선택합니다. 간단한 고지 의무로 재사용 장벽을 낮추면서도 저작권 및 라이선스 고지를 유지할 수 있기 때문입니다. 특허 허여가 중요한 조직 코드로 전환되거나 파생 배포물의 동일 조건 공유가 필요해지면 Apache-2.0 또는 GPL-3.0을 다시 검토합니다.

이 선택은 저장소 기여자의 저작물에 적용됩니다. 제3자 의존성, 이미지 또는 인용 자료에는 각자의 라이선스와 고지가 계속 적용되며, 이 문서는 법률 자문이 아닙니다. 향후 라이선스를 변경할 때는 기존 기여자의 권리와 동의를 별도로 확인해야 합니다.
