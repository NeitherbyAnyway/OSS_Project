# Architecture Decision Records

This directory records decisions that affect how the project is built, measured, or maintained.

## Statuses

- **Proposed**: under discussion; not yet adopted.
- **Accepted**: the team has agreed to use this decision.
- **Deprecated** or **Superseded**: no longer current; link to the replacement ADR when applicable.

Copy [the ADR template](template.md) to a numbered file such as `0002-short-decision-title.md`. Keep the context, decision, consequences, and follow-up work concise, and link related issues or RFC discussions.
